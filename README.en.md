# Cookcademy

A recipe book for iPhone. A Kodeco study project.

## What it does

Recipes are grouped by category. You can open a recipe, mark a favorite, add a new recipe, and edit ingredients and steps. Settings change the list colors and hide optional steps.

The sample already includes a set of recipes. Edits are saved on the device.

## Course

Sample from the book [SwiftUI Apprentice](https://www.kodeco.com/books/swiftui-apprentice). The sample was written by Ben Stone.

## Stack

SwiftUI, Codable, AppStorage.

## Run

```bash
git clone https://github.com/dpogonia/Cookcademy-Kodeco.git
cd Cookcademy-Kodeco
open Cookcademy.xcodeproj
```

Run the **Cookcademy** scheme on an iPhone simulator.
