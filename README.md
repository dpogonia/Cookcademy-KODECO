# Cookcademy

Книга рецептов для iPhone. Учебный проект по книге Kodeco.

## Что умеет приложение

Рецепты разложены по категориям. Можно открыть рецепт, отметить избранное, добавить новый и поправить ингредиенты и шаги. В настройках меняются цвета списка и скрываются необязательные шаги.

В примере уже есть набор рецептов. Свои правки сохраняются на устройстве.

## Курс

Пример из книги [SwiftUI Apprentice](https://www.kodeco.com/books/swiftui-apprentice). Код примера написал Ben Stone.

## Стек

SwiftUI, Codable, AppStorage.

## Запуск

```bash
git clone https://github.com/dpogonia/Cookcademy-KODECO.git
cd Cookcademy-KODECO
open Cookcademy.xcodeproj
```

Запустите схему **Cookcademy** на симуляторе iPhone.
